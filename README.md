# 🚗 OurGarage - Management System 

*(Para a versão em Português, role para baixo / For the Portuguese version, scroll down)*

A C# console application designed to manage the flow of vehicles in a garage. 
This project was developed as a practical exercise in structured programming logic, inspired by the "ourAnimals" challenge, but evolved to demonstrate solid software engineering concepts.

## 💡 Technical Concepts Applied
* **In-Memory CRUD:** Data creation, reading, and validation using multidimensional arrays (`string[,]`).
* **Flow Control and Loops:** Advanced use of `for` loops and `if/else` conditionals for parking space inspection and business rule validation.
* **Layered Architecture:** Clear separation between user interface logic (console Q&A) and data processing logic (search and insertion in the array).
* **Logical Auto-increment:** Dynamic counting system to generate automatic IDs and identify the next free parking space in memory.

## 🛠️ Technologies
* C#

# 🚗 OurGarage - Sistema de Gerenciamento 

Um aplicativo de console em C# projetado para gerenciar o fluxo de veículos em uma garagem. 
Este projeto foi desenvolvido como um exercício prático de lógica de programação estruturada, inspirado no desafio "ourAnimals", mas evoluído para demonstrar conceitos sólidos de engenharia de software.

## 💡 Conceitos Técnicos Aplicados
* **CRUD em Memória:** Criação, leitura e validação de dados utilizando matrizes multidimensionais (`string[,]`).
* **Controle de Fluxo e Loops:** Uso avançado de laços `for` e condicionais `if/else` para inspeção de vagas e validação de regras de negócio.
* **Arquitetura em Camadas:** Separação clara entre a lógica de interface do usuário (perguntas e respostas no console) e a lógica de processamento de dados (busca e inserção na matriz).
* **Auto-incremento Lógico:** Sistema de contagem dinâmica para gerar IDs automáticos e identificar a próxima vaga livre na memória.

## 🛠️ Tecnologias
* C#
